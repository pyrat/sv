### Logs
Logs are automatically generated when daWinchi is running. If for any reason you'd need to check the logs, they can be found under daWinchi/logs. There are four files, "daWinchi-info.log", "daWinchi-error.log", "daWinchi-debug.log" and "daWinchi-silly.log." Please refer to the following list when deciding what kind of log messages you're after. From most prioritized to least prioritized. For instance, if you'd want to see HTTP logs, you would choose "daWinchi-debug.log", because debug is the first log file to include HTTP logs.

0. Error
1. Warn
2. Info
3. HTTP
4. Verbose
5. Debug
6. Silly
